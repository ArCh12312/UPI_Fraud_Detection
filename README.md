# UPI_Fraud_Detection

LightGBM multiclass classifier on engineered features (single-row, entity profile, velocity window and graph relationship features), with per-class probability weights tuned for macro-F1. Validated by time (train Jul-Aug, validate Sep). To run: place this notebook in the same folder as train.csv, test.csv (full file), accounts.csv and merchants.csv, then run all cells in order.
